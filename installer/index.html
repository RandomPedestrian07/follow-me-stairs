Follow-Me installer

Follow-me is a stair light. A radar sensor at the stairs tracks where each person is. An LED strip along the stairs lights the part next to that person, and the lit part moves with them.

This page installs follow-me on an Apollo MTR-1. Version __VERSION__.

Install

Use Chrome or Edge on a computer. Phones and other browsers cannot connect to the sensor over USB.

  1. Connect the MTR-1 to this computer with a USB-C data cable. A charge-only cable does not work.
  2. Click Install Follow-Me and pick the sensor from the list.
  3. When the install is complete, enter your Wi-Fi name and password.
  4. Click Visit device to open the sensor's web page.

This browser cannot install firmware. Open this page in Chrome or Edge on a computer.

The installer works only over HTTPS. Open this page from its https:// address.

Installing erases the sensor. A sensor that already has a follow-me setup must go through the setup wizard again. To keep the setup, update the sensor from ESPHome instead.

After installing

On the sensor's web page, click Set up Follow-Me. The setup wizard asks for the shape of your stairs, has you walk them once, and lines up the LED strip.

If the Wi-Fi step did not appear, connect your phone to the Apollo MTR1 Hotspot network and enter your Wi-Fi there.

WLED needs some settings changed first. The wizard checks them and can change them for you.
